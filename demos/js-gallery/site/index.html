Gapminder in JavaScript charting libraries

The same dataset and the same three views (a bubble chart by year, one country over time, a world map) in three libraries, so you can compare them side by side. Everything is drawn in your browser; the server only sends static files.

  • Apache ECharts

    Timeline-driven bubble chart, line chart and a GeoJSON map series.

  • Chart.js

    Bubble and line charts in core Chart.js; the map uses the chartjs-chart-geo plugin.

  • Plotly.js

    Animation frames with a slider, line chart and a GeoJSON choropleth.
